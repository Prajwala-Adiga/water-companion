# Changelog

## 1.0.0 — 2026-10-16

- Keep the companion hidden while waiting for the next reminder.
- Show Done, Snooze 5 min, and Snooze 10 min actions when water is due.
- Add configurable reminder interval and snooze durations.
- Add optional reminder sound, preferred monitor, and start-with-Windows settings.
- Add a short entrance animation without continuous background animation.
- Add automated scheduling, interface, settings, and Windows smoke tests.
- Add a portable Windows ZIP and per-user Windows installer build pipeline.
